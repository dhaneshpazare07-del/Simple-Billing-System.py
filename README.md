# Simple Billing System — PS No.  33

## Product catalogue
- Rice: Rs. 50
- Sugar: Rs. 40
- Oil: Rs. 120
- GST: 5% of subtotal

## Concepts
Dictionary (product catalogue), list (bill items), functions (validation/calculation/bill generation), and file handling (`bill.txt`).

## Requirements
Python 3 only. No external libraries or pip installation required.

## Validation
Only Rice, Sugar and Oil are accepted (case-insensitive). Quantity must be a whole number of at least 1. Invalid products and quantities are rejected.
